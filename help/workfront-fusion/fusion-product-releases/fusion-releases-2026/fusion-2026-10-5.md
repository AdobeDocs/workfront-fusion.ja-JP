# Workfront Fusion リリースアクティビティ：2026年10月5日の週

ここでは、2026年10月5日の週にAdobe Workfront Fusionで行われたすべての機能強化について説明します。

最近のすべての変更内容のリストについては、[Adobe Workfront Fusion リリースアクティビティ](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md)を参照してください。

Workfront Fusion での最近のバグ修正のリストについては、[Workfront メンテナンスアップデート](https://experienceleague.adobe.com/ja/docs/workfront-known-issues/releases/current-updates)ページで、Workfront Fusion メンテナンスアップデートというラベルが付いたアップデートがあるか確認してください。

## Jira コネクタ：新しいサービスアカウント接続タイプ

チームが認証する方法に一致するJira接続を簡単に作成できるように、Jira コネクタにサービスアカウント API トークンとサービスアカウント OAuth 2の2つの新しい接続タイプを追加しました。

これらのオプションを使用すると、自動化用の接続を作成し、個人ユーザーアカウントではなく専用のJira サービスアカウントとして実行できます。 Jira サービス アカウントがAPI トークンで認証される場合はサービス アカウント API トークンを使用し、環境がサービス アカウントにOAuth 2を使用する場合はサービス アカウント OAuth 2を使用します。

Basic接続タイプとOAuth2接続タイプは引き続き使用できます。

詳しくは、[Jira モジュール ](/help/workfront-fusion/references/apps-and-modules/third-party-connectors/jira-modules-new.md)を参照してください。

## Veeva Vault コネクタで使用できる新しい「複数の注釈を作成」モジュール

複数の注釈を作成モジュールをより使いやすくするために、新しいモジュールに更新しました。 これで、値を指定する前に、プレースマーク、参照、その他の注釈フィールドのフィールドを選択できるようになりました。これにより、設定が簡単になり、優先度の高い値のみに焦点を絞ることができます。

以前に使用可能だった「複数の注釈を作成」モジュールは引き続き使用でき、「レガシー」とマークされます。

Veeva Vault モジュールについて詳しくは、[Veeva Vault モジュール ](/help/workfront-fusion/references/apps-and-modules/third-party-connectors/veeva-vault-modules.md)を参照してください。



## HTTP/リクエストモジュールの作成に再試行ステータスコードを追加します

HTTP リクエストの再試行をより細かく制御できるように、HTTP/リクエストモジュールを作成するフィールドに「再試行ステータスコードを追加」フィールドと「再試行ステータスコードを追加」フィールドを追加しました。

これで、組み込みの再試行可能なコード（408、429、およびすべての5xx応答）に加えて、再試行可能として扱うべきカスタム HTTP ステータスコードを定義できます。 例えば、422の応答を再試行可能にすることができます。 T

詳しくは、[HTTP/リクエストモジュールを作成](/help/workfront-fusion/references/apps-and-modules/universal-connectors/http-module-make-a-request.md)を参照してください。

## HTTP/JWT リクエストモジュールを作成して、署名済みJWT認証をHTTP リクエストに追加します

署名済みJWT認証を必要とするAPIを簡単に呼び出すために、HTTP/JWT リクエストモジュールを追加しました。

このモジュールは、標準のHTTP/リクエストモジュールと同様に機能しますが、提供した要求からJSON Web トークンを自動的に生成して署名し、デフォルトでAuthorization Bearer トークンとしてリクエストに含めます。 これにより、シナリオで別のトークン生成ステップを作成することなく、短期的なJWT ベースのアクセスを必要とするサービスに認証できます。

詳しくは、[HTTP > JWT リクエストモジュールの作成](/help/workfront-fusion/references/apps-and-modules/universal-connectors/http-module-make-a-jwt-request.md)を参照してください。
