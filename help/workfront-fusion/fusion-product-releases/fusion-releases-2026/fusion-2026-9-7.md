# Workfront Fusion リリースアクティビティ：2026年9月7日の週

ここでは、2026年9月7日の週にAdobe Workfront Fusionで行われたすべての機能強化について説明します。

最近のすべての変更内容のリストについては、[Adobe Workfront Fusion リリースアクティビティ](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md)を参照してください。

Workfront Fusion での最近のバグ修正のリストについては、[Workfront メンテナンスアップデート](https://experienceleague.adobe.com/ja/docs/workfront-known-issues/releases/current-updates)ページで、Workfront Fusion メンテナンスアップデートというラベルが付いたアップデートがあるか確認してください。

## カスタム webhookの新しい認証タイプ

API キー認証とHMAC署名という2つの新しい方法を使用して、カスタム Webhookを認証できるようになりました。 API キー認証は、新しいWebhookのデフォルトの認証タイプになりました。 以前の認証タイプは引き続き使用でき、認証なしの場合は空の値を選択できます。

詳しくは、[Web フック](/help/workfront-fusion/references/apps-and-modules/universal-connectors/webhooks-updated.md)を参照してください。

## シナリオの説明で「AIを使用して説明」ボタンを新たに追加

シナリオの設定パネルの「説明」フィールドで「AIを使用して説明」をクリックすると、AIがシナリオのモジュールと設定に基づいて、シナリオの説明を自動的に生成するようになりました。

詳しくは、[&#x200B; シナリオ設定の設定](/help/workfront-fusion/create-scenarios/config-scenarios-settings/configure-scenario-settings.md#description)を参照してください。

## Fusion AEM MCP コネクタ

Adobe Experience Manager独自のMCP （Model Context Protocol）サーバーに平易な英語プロンプトを送信し、AI モデルが実行に必要なAdobe Experience Managerのアクションを決定できるようにします。 この新しい専用コネクタは、1つのモジュールであるProcess a user promptを追加します。

* OAuthを使用してAdobe Experience Managerに接続します。手作業による資格情報は必要ありません。
* 指示を解釈し、必要なAdobe Experience Manager アクション（サイト、アセット、コンテンツフラグメント、フォルダー、コンテンツリポジトリー、コンテンツ AI）を呼び出して実行します。
* AIが実行できる読み取り専用および書き込み/削除アクションを制限できるため、無人シナリオでも予期しない破壊的アクションを実行することはできません。
* Adobeの独自のAI サービスをデフォルトで使用します。必要に応じて、独自のOpenAI、Anthropic Claude、またはAmazon Bedrock キーを使用します。

詳しくは、[Adobe Experience Manager MCP modules](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/aem-mcp-modules.md)を参照してください。
