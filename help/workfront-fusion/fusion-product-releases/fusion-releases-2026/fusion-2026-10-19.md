# Workfront Fusion リリースアクティビティ：2026年10月19日の週

ここでは、2026年10月19日の週にAdobe Workfront Fusionで行われたすべての機能強化について説明します。

最近のすべての変更内容のリストについては、[Adobe Workfront Fusion リリースアクティビティ](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md)を参照してください。

Workfront Fusion での最近のバグ修正のリストについては、[Workfront メンテナンスアップデート](https://experienceleague.adobe.com/ja/docs/workfront-known-issues/releases/current-updates)ページで、Workfront Fusion メンテナンスアップデートというラベルが付いたアップデートがあるか確認してください。

## 新しいマッピング変数

6つの新しい一般変数がマッピングパネルに追加されました。 すぐに使用できるシナリオと実行リンク、API URL、所有権の識別子を提供するので、URLを作成したり、チームや組織のIDをハードコーディングしたりすることなく、これらの値をマッピングされたフィールドに含めることができます。

* `scenarioUrl`: Fusion ユーザーインターフェイスの現在のシナリオへのリンク。
* `executionUrl`: Fusion ユーザーインターフェイスの現在のシナリオ実行へのリンク。
* `scenarioApiUrl`：現在のシナリオのFusion API URL。
* `executionApiUrl`：現在の実行の詳細に関するFusion API URL。
* `teamId`：現在のシナリオを所有するFusion チームのID。
* `organizationId`：現在の実行に関連付けられているFusion組織のID。

これらの変数は、既存の`executionID`、`scenarioID`、`scenarioName`、`triggerTimestamp`および`operationsConsumed`変数を拡張します。

詳しくは、[一般関数](/help/workfront-fusion/references/mapping-panel/functions/general-functions.md)を参照してください。

## Fusion コネクタの変更

Workfront Fusion コネクタでは、シナリオ内からFusion組織を管理するためのより多くのアクションがサポートされるようになりました。

**新しいモジュールとアクション**

* **レコードを複製：** フックを複製できるようになりました。 シナリオを複製する場合と同様に、依存関係を使用してソースフックの依存関係をターゲットにマッピングします。
* **レコードの削除：**&#x200B;接続、データストア、データストアレコード、データストアレコード（一括）、データ構造、フック、キー、シナリオ、またはチームを削除できるようになりました。
* **レコードのリスト：** DLQ、組織、チーム、ユーザーをリストできるようになりました。
* **レコードを読み取る：** DLQ、現在の組織、チーム、ユーザー、または承認済みユーザーを読み取れるようになりました。
* **レコードの依存関係を取得：** フックの依存関係を取得できるようになりました。
* **レコードの依存関係を取得：**&#x200B;この新しいモジュールは、データストア、フック、シナリオの依存関係を返します。 リソースを削除する前に実行し、何かがリソースに依存しているかどうかを確認します。

**その他の更新**

* 複数値としてマークされたプロパティフィルターが、`==`および`!=`演算子でコンマ区切りの値を受け入れるようになりました。 現在、ユーザーの`id` プロパティのみがサポートしています（例：`id==123,456`）。
* フックのキューを削除する場合、`except` パラメーターは`excludeId`に置き換わり、すべての項目を削除する場合にのみ使用できます。 `id` パラメーターは、コンマ区切りのリストを受け入れるようになりました。 削除が既に進行中の場合、新しい423応答が返されます。
* シナリオまたは単一のシナリオを取得する際に、`fields` パラメーターを使用して、返されるフィールドを選択できるようになりました。

詳しくは、[Workfront Fusion modules](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/workfront-fusion-modules.md)を参照してください。

## Adobe Fusion MCP コネクタ

新しいAdobe Fusion MCP コネクタを使用すると、シナリオ内から自然言語プロンプトをAdobe Fusion MCP サーバーに送信できます。 大規模言語モデル（LLM）は、リクエストを解釈し、それを完了するために必要なFusion ツールを呼び出します。

コネクタは、ホストされているAdobe Fusion MCP エンドポイントでのみ機能します。

詳しくは、[Adobe Fusion MCP モジュール &#x200B;](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/adobe-fusion-mcp-modules.md)を参照してください。
