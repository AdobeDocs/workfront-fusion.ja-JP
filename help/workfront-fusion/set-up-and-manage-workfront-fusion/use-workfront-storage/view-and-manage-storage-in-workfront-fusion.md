# Workfront Fusionでのストレージの表示と管理

Workfront Fusionのストレージエリアでは、Adobe クラウドストレージ内のリポジトリを表示したり、操作したりできます。

ストレージの概要については、[&#x200B; ストレージの概要](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-workfront-storage/storage-overview.md)を参照してください。

>[!TIP]
>
>リポジトリを表示する前に、ストレージを初期化する必要があります。 手順については、[&#x200B; ストレージの初期化](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-workfront-storage/initialize-storage.md)を参照してください。

## リポジトリ、フォルダー、ファイルの表示

1. Workfront Fusionで、左側のナビゲーションで「**ストレージ**」をクリックします。
リポジトリのリストが開きます。

   利用可能なリポジトリが1つしかない場合、リポジトリが直接開きます。

1. 任意のリポジトリの&#x200B;**開く**&#x200B;をクリックして、その内容を参照します。

   リポジトリを開くと、リポジトリ内にフォルダーが表示されます。
1. フォルダーをクリックして開き、そのファイルを表示します。
1. フォルダー構造内を移動するには、パンくずリストをクリックします。


>[!NOTE]
>
>空のフォルダーに次のメッセージが表示されます：*「このフォルダーは空です」*

## 複数のストレージ接続の管理

1つのチームで複数のAdobe ストレージ接続を持つことができます。

1. Workfront Fusionで、左側のナビゲーションで「**ストレージ**」をクリックします。
複数の接続が存在する場合、タブは、各接続の名前でラベル付けされたストレージ ページの上部に表示されます。
1. 別の接続のリポジトリに切り替えるには、その接続のタブをクリックします。

トークンの有効期限が切れて更新できなかった場合など、接続が無効になった場合は、自動的に除外され、タブとして表示されません。 Fusionのスケジュールされたトークンの更新により、接続は自動的に有効になります。

## ファイル情報

表の各ファイルには、次の内容が表示されます。

| 列 | 説明 |
| -------- | ------------- |
| **名前** | ドキュメントアイコンを含むファイル名。 |
| **タイプ** | PNG、PDF、JPGなどのファイル拡張子バッジ。 |
| **サイズ** | ファイルサイズ： ファイルが最近アップロードされ、バックエンドがまだ処理中である場合、*「処理中…」*&#x200B;が表示されます。 |
| **作成日** | 作成日： |

複数のバージョンが存在する場合、ファイルには&#x200B;**バージョンバッジ** （例：`v2`、`v3`）も表示されます。

## テーブルコントロール

* **検索/フィルター**：グローバル検索バーを使用して、名前でファイルをフィルタリングします。
* **並べ替え**：列ヘッダーをクリックして並べ替えます。
* **Pagination**: ページごとに10、25、50、または100 アイテムを選択します。 デフォルトは25です。
