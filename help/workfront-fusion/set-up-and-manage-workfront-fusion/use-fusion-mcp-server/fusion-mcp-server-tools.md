# Adobe Workfront Fusion MCP Server Tools


この記事では、Adobe Workfront Fusion MCP サーバーが接続されたAI エージェントに公開するツールの一覧を示します。 エージェントは、Fusion項目の検索、検査、作成、実行、更新、削除を依頼する際に、これらのツールを代わりに呼び出します。

サポートされているすべてのサーフェスで同じツールを使用できます。Claude、ChatGPT、Copilot、または独自のエージェントのカスタム MCP接続と、スタンドアロンとFusionの右側のパネルの両方のCoworkerです。 設定については、[Adobe Workfront Fusion MCP サーバーの設定](configure-fusion-mcp-server.md)を参照してください。

エージェントは、Adobe ID、Fusion組織のロール、およびチームのロールを使用してFusionで動作します。 ツールは、Fusionで対応する権限がある場合にのみ機能します。 Adobeは、お客様のFusion データに対してエージェントが行った変更について責任を負いません。

## 読み取りと書き込みのアクション

各ツールは次のように分類されます。

* **読み取り**：シナリオのリスト表示や実行の取得など、何も変更せずに情報を取得します。
* **書き込み**: シナリオの複製やWebhook キューのクリアなど、Fusion データを作成、変更、実行、削除します。

## 組織ツール

アクティブな組織は、現在のセッション内の他のすべてのツールに適用されます。

| ツール | 名前 | アクション | 説明 |
| --- | --- | --- | --- |
| 組織のリスト | `fusion_orgs_list` | 読み取り | アクセスできるFusion組織を、ID、地域（ゾーン）、ラベル付きで一覧表示します。 |
| アクティブな組織を設定 | `fusion_orgs_set` | Session | 現在のセッションのアクティブな組織を切り替えます。 Fusion データは変更されません。 |

## シナリオツール

### シナリオ

| ツール | 名前 | アクション | 説明 |
| --- | --- | --- | --- |
| シナリオをリストする | `fusion_scenarios_list` | 読み取り | 組織内のシナリオのリストを表示します。 |
| シナリオを入手 | `fusion_scenarios_get` | 読み取り | 完全なブループリントを含むシナリオを返します。 |
| シナリオの依存関係を取得 | `fusion_scenarios_getDependencies` | 読み取り | シナリオのブループリント参照の接続、キー、データストア、データ構造、およびwebhookを返します。 |
| 依存シナリオの検索 | `fusion_scenarios_dependents` | 読み取り | 特定のWebhook、データストア、データ構造、接続、キー、またはシナリオを参照するシナリオを検索します。 リソースを変更または削除する前の影響分析に役立ちます。 |
| ブループリントの検証 | `fusion_scenarios_validate_blueprint` | 読み取り | ブループリントを保存することなく、チーム（モジュール参照、接続、必須フィールド）と照らし合わせて構造的に検証します。 |
| シナリオの作成 | `fusion_scenarios_create` | 編集 | ブループリントからチーム内のシナリオを作成し、オプションの名前、説明、フォルダー、スケジュール、および順次処理を行います。 |
| コピーシナリオ | `fusion_scenarios_clone` | 編集 | シナリオを同じチームまたは別のチームに複製します。 チームをまたいで複製する場合は、各接続、Webhook、データストア、データ構造、キーをターゲットリソースにマッピングします。 オプションで、最後に処理されたレコードから続行します。 |
| シナリオの更新 | `fusion_scenarios_update` | 編集 | 名前、説明、フォルダー、スケジュール、またはアクティブな状態（アクティブ化/非アクティブ化）を変更します。 また、削除されたシナリオを復元することもできます。 |
| シナリオを1回実行 | `fusion_scenarios_execute` | 編集 | シナリオを1回実行し、結果を（最大タイムアウトまで）待ち、ステータスとエラーメッセージを返します。 インスタント（Webhook トリガー）シナリオではサポートされていません。 |
| シナリオの削除 | `fusion_scenarios_delete` | 編集 | シナリオを削除します。 削除されたシナリオは、**シナリオの更新**&#x200B;で復元できます。 |

プロンプトの例：

* _マーケティング チームのアクティブなシナリオのうち、6か月間に編集されていないものはどれですか？_
* _「Salesforce → Workfront sync」シナリオで使用する接続は何ですか？_
* _セールス部門に「リード取り込み」を複製し、セールスSalesforceとの連携でスワップします。_
* _このブループリントを読み込む前に検証します。_
* _「Nightly レポート」を一度実行して、成功するかどうかを教えてください。_

### シナリオバージョン

| ツール | 名前 | アクション | 説明 |
| --- | --- | --- | --- |
| シナリオのバージョンのリスト | `fusion_scenario_versions_list` | 読み取り | シナリオの保存されたバージョンを一覧表示します。 `version`、`createdAt`、`comment`でフィルタリングします。 |
| シナリオのバージョンを取得 | `fusion_scenario_versions_get` | 読み取り | 特定のバージョンのブループリントとメタデータを返します。 |

プロンプトの例：

* _このシナリオのバージョン 12とバージョン 14の間で何が変更されましたか？_

## 運用ツール

| ツール | 名前 | アクション | 説明 |
| --- | --- | --- | --- |
| 実行リストの表示 | `fusion_executions_list` | 読み取り | シナリオまたは不完全な実行の実行をリストします。 `status` （例：エラーの場合は`status==3`、警告の場合は`status==2`）、`timestamp`、`duration`、`bundles`、`operations`、`transfer`でフィルタリングします。 オプションで、チェック実行を含めます。 |
| 実行する | `fusion_executions_get` | 読み取り | シナリオまたは不完全な実行に関する1つの実行とメタデータを返します。 |

プロンプトの例：

* _昨日の「請求書同期」の実行に失敗した件を表示し、エラーを要約します。_
* _今週、最も多くの操作を使用したこのシナリオの実行はどれですか？_

## 運用（使用状況）ツール

| ツール | 名前 | アクション | 説明 |
| --- | --- | --- | --- |
| オペレーションの取得 | `fusion_operations_get` | 読み取り | 1年までの日付範囲の運用時系列（日別または月別）を返します。 チーム、シナリオ、またはパッケージでフィルターを実行し、モジュール、パッケージ、シナリオ、またはチームごとにグループ化します。 |
| 操作の概要を取得 | `fusion_operations_summary_by_org` | 読み取り | 日付範囲のシナリオとチームごとの合計操作に加えて、全体の合計を返します。 |

プロンプトの例：

* _先月のオペレーション別の上位10 シナリオ。_
* _第3四半期にSalesforce アプリが使用した操作の数は？_

## 連携と主要ツール

これらのツールは、メタデータのみを返します。 資格情報、トークン、秘密値は返されません。

| ツール | 名前 | アクション | 説明 |
| --- | --- | --- | --- |
| 接続を検索 | `fusion_connections_search` | 読み取り | 接続を一覧表示します。 `name`、`accountName`、`accountType`、`expire`、`teamId`、`scopesCount`、`editable`、`environmentType`、`authenticationType`でフィルタリングします。 |
| つながる | `fusion_connections_get` | 読み取り | 1つの接続の詳細を返します。 |
| 検索キー | `fusion_keys_search` | 読み取り | キーを一覧表示します。 `name`、`typeName`、`teamId`でフィルタリングします。 |
| キーを取得 | `fusion_keys_get` | 読み取り | 単一のキーの詳細を返します。 |

プロンプトの例：

* _今後30日以内に有効期限が切れる接続と、それを使用するシナリオを選択してください。_

## Webhook ツール

### Webhook

| ツール | 名前 | アクション | 説明 |
| --- | --- | --- | --- |
| Web フックをリスト表示 | `fusion_hooks_list` | 読み取り | Webhook （フック）を一覧表示します。 `name`、`teamId`、`type`、`enabled`、`gone`、`typeName`、`scenarioId`、`priority`、`detached`などでフィルタリングします。 |
| Webhookを入手 | `fusion_hooks_get` | 読み取り | Webhookの設定、所有者のバインディングおよび外部参照を返します。 |
| 依存するWebhookの検索 | `fusion_hooks_dependents` | 読み取り | 特定の接続を参照するWebhookを検索します。 |

### Webhook キュー

| ツール | 名前 | アクション | 説明 |
| --- | --- | -------- | --- |
| キューの統計情報を取得 | `fusion_queue_stats` | 読み取り | キューに入れられたイベントの数、キュー制限、およびwebhookが有効かどうかを返します。 |
| リストキュー | `fusion_queue_list` | 読み取り | 処理待ちのWebhook イベントを受信したリストです。 |
| キュー項目を取得 | `fusion_queue_get` | 読み取り | デコードされたペイロードを含む、キューに入った1つのイベントを返します。 |
| キュー項目の削除 | `fusion_queue_delete` | 編集 | 特定のキューに入ったイベント（最大50）を削除するか、キューをクリアします（オプションで一部のイベントを除く）。 現在処理中のイベントは削除できません。 |

プロンプトの例：

* _Webhookの「フォーム送信」はバックアップされていますか？_
* _最も古いキューに入れられたイベントのペイロードを表示します。_

## データストアとデータ構造のツール

| ツール | 名前 | アクション | 説明 |
| --- | --- | --- | --- |
| データストアをリスト表示 | `fusion_datastores_list` | 読み取り | レコード数、サイズ、最大サイズのデータストアを一覧表示します。 |
| データストアを取得 | `fusion_datastores_get` | 読み取り | データストアのメタデータと使用状況、リンクされたデータ構造、厳密な検証設定を返します。 |
| データストアレコードのリスト | `fusion_data_list` | 読み取り | オフセットページングを使用して、データストアからレコード（キー+ JSON データ）を読み取ります。 |
| 依存データストアの検索 | `fusion_datastores_dependents` | 読み取り | 特定のデータ構造を使用するデータストアを検索します。 |
| 検索データ構造 | `fusion_data_structures_search` | 読み取り | データ構造のリスト。 `name`、`strict`、`teamId`でフィルタリングします。 |

## アクティビティログツール

| ツール | 名前 | アクション | 説明 |
| --- | --- | --- | --- |
| アクティビティログのリスト | `fusion_activity_logs_list` | 読み取り | 組織（誰が何をしたか、どのエンティティに、いつ）の監査イベントをリストします。 `entity` （例：`scenario`、`connection`、`webhook`、`data store`、`user`）、`action` （例：`created`、`deleted`、`updated`、`transferred ownership`）、ユーザー、チーム、タイムスタンプでフィルタリングします。 |
| アクティビティログの書き出し | `fusion_activity_logs_export` | 読み取り | 同じフィルターを使用して、アクティビティログをCSVまたはXLSXとして書き出します。 |

プロンプトの例：

* _すべての接続の変更を今四半期にExcelにエクスポートします。_

## 同僚

この記事のすべてのツールは、スタンドアロンおよびFusionの右側のパネルで、同じ読み取り/書き込み設定と権限の対象となるCoworkerで使用できます。

## ツールの更新方法

Adobeが新しいバージョンのFusion MCP サーバーをリリースすると、接続されたエージェントが更新されたツールセットを自動的にピックアップします。 再接続する必要はありません。
